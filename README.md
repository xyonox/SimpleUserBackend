# SimpleUserBackend

SimpleUserBackend is a small backend application written in Go.
The project was created as a learning project for:

- How to write a REST API in Go
- How to manage users, authentication and authorization
- How to use a database
- encrypting passwords
- how to use JWTs
- how to work with multiple files
